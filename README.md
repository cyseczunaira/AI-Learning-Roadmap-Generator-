# 🎓 AI Learning Roadmap Generator

An AI-powered application that creates personalized learning roadmaps based on the user's learning domain, skill level, available learning time, and uploaded study material.

## 🚀 Features

- Enter any learning domain
- Select skill level:
  - Beginner
  - Intermediate
  - Advanced
- Enter available learning time
- Upload study materials
- Supports PDF, TXT, and DOCX files
- Generates a personalized learning roadmap using AI
- Provides:
  - Learning goals
  - Prerequisites
  - Week-by-week learning plan
  - Topics to study
  - Practical exercises
  - Projects
  - Study schedule
  - Final assessment
  - Expected skills

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Large Language Model (LLM)
- PyPDF
- python-docx
- Google Colab
- Cloudflare Tunnel

## 🧠 How It Works

1. The user enters a learning domain.
2. The user selects their skill level.
3. The user enters the available learning time.
4. The user can upload study material.
5. The application extracts text from the uploaded files.
6. The information is sent to the Groq AI model.
7. The AI generates a personalized learning roadmap.
8. The roadmap is displayed through the Streamlit interface.

## 📂 Supported Files

The application supports:

- PDF
- TXT
- DOCX
